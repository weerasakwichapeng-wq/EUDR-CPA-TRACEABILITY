# EUDR-CPA-TRACEABILITY

ระบบตรวจสอบย้อนกลับแหล่งที่มาวัตถุดิบยางพารา สำหรับงาน FSC Chain of Custody และ EUDR
(EU Deforestation Regulation) — ครอบคลุมทะเบียนแหล่งวัตถุดิบ ทะเบียนแปลงปลูก แผนที่ดาวเทียม
พร้อมชั้นขอบเขตการปกครองและพื้นที่อนุรักษ์ และระบบตัดโควต้ารับซื้อรายแปลงอัตโนมัติ

## เว็บที่เผยแพร่

**https://weerasakwichapeng-wq.github.io/EUDR-CPA-TRACEABILITY/**

เว็บเวอร์ชันนี้ตัดข้อมูลอ่อนไหวออกก่อนเผยแพร่เสมอ — **ไม่มี**เลขบัตรประชาชนเกษตรกร
และ**ไม่มี**เบอร์โทรศัพท์ผู้ขาย (ดูหัวข้อ "การจัดการข้อมูลส่วนบุคคล" ด้านล่าง)

## โครงสร้าง repo

```
eudr-web/          ซอร์สโค้ดของเว็บแอป (index.html, assets/, สคริปต์สร้างฐานข้อมูลใน tools/)
docs/              เว็บเวอร์ชันเผยแพร่สาธารณะ (GitHub Pages เสิร์ฟจากโฟลเดอร์นี้)
```

รายละเอียดการทำงานของระบบทั้งหมด — สูตรคำนวณโควต้า ระบบตัดโควต้าอัตโนมัติ การแบ่งประเภท
แหล่งวัตถุดิบ ที่มาของขอบเขตการปกครอง/พื้นที่อนุรักษ์ ฯลฯ อยู่ที่ **[eudr-web/README.md](eudr-web/README.md)**

## การจัดการข้อมูลส่วนบุคคล

ไฟล์ฐานข้อมูลจริง (`eudr-web/data/`) ซึ่งสร้างจากไฟล์ Excel ต้นทางที่มีชื่อ เบอร์โทร
และเลขบัตรประชาชนของเกษตรกร/ผู้ขาย **ไม่ถูก commit ขึ้น repo นี้** (ดู `.gitignore`)
เก็บไว้ในเครื่องของผู้ดูแลระบบเท่านั้น

เว็บที่เผยแพร่ที่ `docs/index.html` สร้างจากสคริปต์ `eudr-web/tools/build-pages.js`
ซึ่งตัดฟิลด์ `citizenId` (เลขบัตรประชาชน) และ `phone` (เบอร์โทรศัพท์) ออกทุกครั้งก่อนสร้างไฟล์
ข้อมูลที่เหลือ (ชื่อเกษตรกร พิกัดแปลง เลขที่เอกสารสิทธิ์) เป็นข้อมูลที่จำเป็นต่อการตรวจสอบ
ย้อนกลับตามเกณฑ์ EUDR/FSC โดยตรง

## อัปเดตเว็บที่เผยแพร่

จากเครื่องที่มีไฟล์ Excel ต้นทาง (ดู [eudr-web/README.md](eudr-web/README.md) สำหรับลำดับ
ขั้นตอนสร้างฐานข้อมูลทั้งหมด) รันคำสั่งสุดท้ายนี้เพิ่มเพื่อสร้างเว็บสาธารณะ:

```bash
node eudr-web/tools/build-pages.js
git add docs/
git commit -m "อัปเดตเว็บสาธารณะ"
git push
```

GitHub Pages จะอัปเดตให้อัตโนมัติภายในไม่กี่นาทีหลัง push
